# Simple 3: /design スキル

書籍 第 2 章「簡易スキルで仕様駆動する」の /design 呼び出し完了時点のスナップショット。

## このステップで追加したもの

- `design/001_minimum_kanban.md` = 軽量設計 1 file

## 設計に含めたもの

- Board / List / Card のデータモデルと関係
- 各 API のメソッド / パス / 入力 / 成功時レスポンス / 異常系
- ボード一覧画面とボード詳細画面の表示要素と操作
- タイトルのバリデーションと失敗時の扱い
- 実装順序

## 設計に含めなかったもの

- 認証、 権限管理、 メンバー招待
- ドラッグ&ドロップ
- 削除と復元
- Atomic Design による UI 階層設計

## 判断固定のポイント

- 親不在 (404) と バリデーション (400) 同時成立時は 404 優先
- Card 更新 body は title 以外の field を無視 (description / order / listId 更新は本 spec 対象外)
- インライン編集で値未変更なら API 呼び出しスキップ (client 側判定)

## 補足

- 仕様間の矛盾なし (共通ルール 005 を土台に 001-004 が差分を積む構造で整合)
- AskUserQuestion 発火数 = 0
