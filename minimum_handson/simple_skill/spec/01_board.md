# ボードの仕様

## 概要

ボードの一覧表示と新規作成を行う。ボード一覧画面（`app/page.tsx`）で作成済みボードをカード形式で表示し、各カードからボード詳細（`/boards/[id]`）へ遷移する。共通ルールは spec/00_common.md に従う。

## データモデル

- Board は `id`、`title`、`createdAt` を持つ。

## 機能要件

### FR-101 ボード一覧表示

- 入力 なし
- 条件 ボード一覧画面を開いたとき
- 出力 作成済みボードのカード一覧
- 振る舞い 作成済みのボードをカード形式で `createdAt` の降順に表示する。各ボードカードは `/boards/[id]` へのリンクになっている。

### FR-102 ボード作成フォームの表示

- 入力 「新規ボード作成」ボタンの押下
- 条件 ボード一覧画面
- 出力 タイトル入力フォーム
- 振る舞い ボタンを押すとタイトル入力フォームが表示される。

### FR-103 ボード作成

- 入力 タイトル（文字列）
- 条件 フォーム送信時
- 出力 作成されたボード（`id`、`title`、`createdAt`）
- 振る舞い タイトルをトリム後に検証し、有効なら Board を作成する。作成後、一覧に新しいボードが表示される（`createdAt` 降順の先頭）。

### FR-104 ボード一覧取得 API

- 入力 なし
- 条件 GET `/api/boards`
- 出力 `createdAt` 降順のボード配列
- 振る舞い 全ボードを `createdAt` 降順で返す。クライアント側の一覧更新に使う。

### FR-105 ボード作成 API

- 入力 `{ "title": string }`
- 条件 POST `/api/boards`
- 出力 作成された Board
- 振る舞い トリム後のタイトルを検証し、有効ならボードを作成して返す。

## 異常系

| ID | 条件 | HTTP ステータス | レスポンス |
|---|---|---|---|
| E-101 | title がトリム後に空文字 | 400 | `{ "error": { "code": "VALIDATION_ERROR", "message": "タイトルは1〜100文字で入力してください" } }` |
| E-102 | title がトリム後に100文字超 | 400 | `{ "error": { "code": "VALIDATION_ERROR", "message": "タイトルは1〜100文字で入力してください" } }` |

## 境界条件

- タイトル トリム後 0文字 → エラー
- タイトル トリム後 1文字 → 成功
- タイトル トリム後 100文字 → 成功
- タイトル トリム後 101文字 → エラー

## バリデーション

| フィールド | 必須 | 制約 |
|---|---|---|
| title | はい | 前後の半角・全角空白・タブ・改行を除去してから 1〜100文字。トリム後の値を保存する |

## 並び順

- ボード一覧は `createdAt` の降順で表示する。
