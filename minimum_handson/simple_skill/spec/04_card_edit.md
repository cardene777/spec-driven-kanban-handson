# カードタイトル編集の仕様

## 概要

ボード詳細画面上でカードのタイトルをクリックするとインライン編集でき、フォーカスを外すと自動保存する。保存は PATCH /api/cards/[id] で行う。

## 機能要件

### FR-001 カードタイトルのインライン編集開始

- 入力 カードタイトルのクリック
- 条件 表示中のカード
- 出力 編集可能な入力欄
- 振る舞い タイトルをクリックすると、現在のタイトルを初期値とする入力欄に切り替わる。

### FR-002 カードタイトルの自動保存

- 入力 編集後のフォーカスアウト（blur）
- 条件 入力値が trim 後 1〜200文字
- 出力 更新後の表示
- 振る舞い フォーカスアウト時に PATCH /api/cards/[id] を呼ぶ。値が変更されていない場合は API を呼ばず表示に戻してもよい。

### FR-003 カード更新API

- 入力 card の id と `{ title: string }`（PATCH /api/cards/[id]）
- 条件 指定カードが存在し、title が trim 後 1〜200文字
- 出力 200 と更新後の Card `{ id, title, description, order, listId, createdAt }`
- 振る舞い trim 後の title でカードを更新して返す。

## 異常系

| ID | 条件 | HTTPステータス | レスポンス |
|---|---|---|---|
| E-001 | title が trim 後 0文字 | 400 | `{ "error": { "code": "VALIDATION_ERROR", "message": "titleは1〜200文字で入力してください" } }` |
| E-002 | title が trim 後 201文字以上 | 400 | 同上 |
| E-003 | 指定 card の id が存在しない | 404 | `{ "error": { "code": "NOT_FOUND", "message": "指定されたカードが見つかりません" } }` |

## 境界条件

- title trim後 0 / 1 / 200 / 201文字 → エラー / 成功 / 成功 / エラー
- 空白のみ → trim後0文字 → エラー（保存されず、直前の値を保持）
- 値が未変更のままフォーカスアウト → 変更なし（API呼び出し省略可）
- 存在しない cardId → 404

## バリデーション

| フィールド | 必須 | 制約 |
|---|---|---|
| title | はい | 文字列、trim後1〜200文字 |
| cardId（パス） | はい | 既存の Card.id |
