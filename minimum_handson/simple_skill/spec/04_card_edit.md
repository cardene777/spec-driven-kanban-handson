# カードタイトル編集の仕様

## 概要

ボード詳細画面上でカードのタイトルをクリックするとインライン編集でき、フォーカスを外すと自動保存する。保存は PATCH `/api/cards/[id]` で行う。

## 機能要件

### FR-001 カードタイトルのインライン編集開始

- 入力 カードタイトルのクリック
- 条件 表示中のカード
- 出力 編集可能な入力欄
- 振る舞い タイトルをクリックすると、現在のタイトルを初期値とする入力欄に切り替わる。

### FR-002 カードタイトルの自動保存

- 入力 編集後のフォーカスアウト（blur）
- 条件 入力値を trim した結果が 1〜200 文字
- 出力 更新後の表示
- 振る舞い フォーカスアウト時に PATCH `/api/cards/[id]` を呼び、成功したら表示を新しい title に更新する。値が変更されていない場合は API 呼び出しを省略してもよい。エラー時は元の title に戻し、UI 上にエラーを表示する。

### FR-003 カード更新API

- 入力 card の id と `{ title: string }`（PATCH `/api/cards/[id]`）
- 条件 指定カードが存在し、title を trim した結果が 1〜200 文字
- 出力 200 と更新後の Card `{ id, title, description, order, listId, createdAt }`
- 振る舞い trim 後の title で該当カードを更新して返す。

## 異常系

| ID | 条件 | HTTP ステータス | レスポンス |
|---|---|---|---|
| E-001 | 指定 card の id が存在しない | 404 | `{ "error": { "code": "NOT_FOUND", "message": "指定されたカードが見つかりません" } }` |
| E-002 | 対象カードは存在し、title trim 後 0 文字 | 400 | `{ "error": { "code": "VALIDATION_ERROR", "message": "titleは1〜200文字で入力してください" } }` |
| E-003 | 対象カードは存在し、title trim 後 201 文字以上 | 400 | 同上 |

判定順序は 00_common.md に従い、対象カードが存在しない場合は 404 を先に返す（body に不正な title が含まれていても 400 を返さない）。

## 境界条件

- title trim 後 0 / 1 / 200 / 201 文字 → エラー / 成功 / 成功 / エラー
- 半角・全角空白、タブ、改行のみ → trim 後 0 文字 → エラー（保存されず、直前の値を保持）
- 値が未変更のままフォーカスアウト → 変更なし（API 呼び出し省略可）
- 存在しない cardId → 404

## バリデーション

| フィールド | 必須 | 制約 |
|---|---|---|
| title | はい | 文字列。trim（前後の半角・全角空白、タブ、改行を除去）後 1〜200 文字 |
| cardId（パス） | はい | 既存の Card.id |

## 並び順

- カードの並び順は 03_card.md の order 規約に従う。編集では order を変更しない。
