# カードタイトル編集の仕様

## 概要

ボード詳細画面で、既存カードのタイトルをインライン編集できるようにする。共通ルールは spec/00_common.md に従う。

## 機能要件

### FR-401 インライン編集の開始

- 入力 カードタイトルのクリック
- 条件 ボード詳細画面
- 出力 編集用の入力フィールド
- 振る舞い カードのタイトルをクリックすると、その場でタイトルを編集できる入力フィールドに切り替わる。

### FR-402 フォーカスアウトで自動保存

- 入力 編集後の入力フィールドからフォーカスが外れること（blur）
- 条件 インライン編集中
- 出力 更新された Card
- 振る舞い 編集後にフォーカスを外すと、自動でタイトルを保存する。トリム後のタイトルを検証し、有効なら更新する。

### FR-403 カード更新 API

- 入力 カード ID（パス）、`{ "title": string }`
- 条件 PATCH `/api/cards/[id]`
- 出力 更新された Card
- 振る舞い 対象カードの存在を先に確認し、存在すればトリム後のタイトルを検証して更新する。

## 異常系

| ID | 条件 | HTTP ステータス | レスポンス |
|---|---|---|---|
| E-401 | 対象カードが存在しない | 404 | `{ "error": { "code": "NOT_FOUND", "message": "カードが見つかりません" } }` |
| E-402 | 対象カードは存在し、title がトリム後に空文字 | 400 | `{ "error": { "code": "VALIDATION_ERROR", "message": "タイトルは1〜200文字で入力してください" } }` |
| E-403 | 対象カードは存在し、title がトリム後に200文字超 | 400 | `{ "error": { "code": "VALIDATION_ERROR", "message": "タイトルは1〜200文字で入力してください" } }` |

## 境界条件

- 存在しないカード ID の編集は 404 を返す（不正な入力があっても 404 を優先）
- タイトル トリム後 0文字 → エラー（更新されない）
- タイトル トリム後 1文字 → 成功
- タイトル トリム後 200文字 → 成功
- タイトル トリム後 201文字 → エラー（更新されない）

## バリデーション

| フィールド | 必須 | 制約 |
|---|---|---|
| title | はい | 前後の半角・全角空白・タブ・改行を除去してから 1〜200文字。トリム後の値を保存する |

## 並び順

- カード編集では `order` を変更しない。
