# リストの仕様

## 概要

ボード詳細画面で、対象ボードに属するリストの一覧表示と新規作成を行う。共通ルールは spec/00_common.md に従う。

## データモデル

- List は `id`、`title`、`order`、`boardId`、`createdAt` を持つ。
- List は Board に属する（`boardId`）。

## 機能要件

### FR-201 リスト一覧表示

- 入力 対象ボード
- 条件 ボード詳細画面を開いたとき
- 出力 対象ボードに属するリスト一覧
- 振る舞い 同じボード内では `order` の昇順で並べて表示する。

### FR-202 リスト作成フォームの表示

- 入力 「リスト作成」ボタンの押下
- 条件 ボード詳細画面
- 出力 タイトル入力フォーム
- 振る舞い ボタンを押すとタイトル入力フォームが表示される。

### FR-203 リスト作成

- 入力 タイトル（文字列）
- 条件 フォーム送信時
- 出力 作成された List
- 振る舞い トリム後のタイトルを検証し、有効なら List を作成する。`order` は同じボード内に0件なら0、以後は最大 `order` + 1 を割り当てる。

### FR-204 リスト一覧取得 API

- 入力 ボード ID（パス）
- 条件 GET `/api/boards/[id]/lists`
- 出力 対象ボードのリスト配列（`order` 昇順）
- 振る舞い 対象ボードのリストを `order` 昇順で返す。クライアント側の一覧更新に使う。

### FR-205 リスト作成 API

- 入力 ボード ID（パス）、`{ "title": string }`
- 条件 POST `/api/boards/[id]/lists`
- 出力 作成された List
- 振る舞い 対象ボードの存在を先に確認し、存在すればトリム後のタイトルを検証して List を作成する。

## 異常系

| ID | 条件 | HTTP ステータス | レスポンス |
|---|---|---|---|
| E-201 | 対象ボードが存在しない | 404 | `{ "error": { "code": "NOT_FOUND", "message": "ボードが見つかりません" } }` |
| E-202 | 対象ボードは存在し、title がトリム後に空文字 | 400 | `{ "error": { "code": "VALIDATION_ERROR", "message": "タイトルは1〜100文字で入力してください" } }` |
| E-203 | 対象ボードは存在し、title がトリム後に100文字超 | 400 | `{ "error": { "code": "VALIDATION_ERROR", "message": "タイトルは1〜100文字で入力してください" } }` |

## 境界条件

- 存在しないボード ID へのリスト作成は、body に不正なタイトルがあっても 404 を優先する（対象が存在する場合だけ 400 バリデーションを行う）
- タイトル トリム後 0/1/100/101文字の判定はボードと同じ

## バリデーション

| フィールド | 必須 | 制約 |
|---|---|---|
| title | はい | 前後の半角・全角空白・タブ・改行を除去してから 1〜100文字。トリム後の値を保存する |
| boardId | はい | 既存の Board を指すこと |

## 並び順

- 同じボード内では `order` の昇順で並べる。
- 0件なら `order` は0、以後は同じボード内の最大 `order` + 1。同じボード内で `order` を重複させない。
