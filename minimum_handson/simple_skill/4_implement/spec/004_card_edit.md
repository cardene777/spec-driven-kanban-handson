# カードタイトル編集の仕様

## 概要

ボード詳細画面上でカードのタイトルをクリックするとインライン編集モードに切り替わり、編集後にフォーカスを外すと自動で保存される。保存は PATCH `/api/cards/[id]` で行う。

## 機能要件

### FR-001 インライン編集モードへの切替

- 入力 カードのタイトル部分のクリック
- 条件 対象カードが画面に表示されているとき
- 出力 タイトル表示要素が編集可能な input / contentEditable 等に置き換わり、初期値として現在の title が入る
- 振る舞い フォーカスは自動的に編集要素へ移る。同一カード上での再クリックは冪等 (すでに編集モードなら何もしない)。同一画面上で複数カードを同時に編集モードにしてもよい (制約なし)。

### FR-002 編集後の自動保存 (blur)

- 入力 編集要素からフォーカスが外れる (blur イベント)
- 条件 編集モードに入っていて編集内容が確定したとき
- 出力 PATCH `/api/cards/[id]` を呼び出し、表示は編集モードから閲覧モードへ戻る
- 振る舞い trim 後の値を送信する。値が変更されていない (元の title と同一) 場合は API を呼ばず閲覧モードへ戻ってよい。API 成功時は最新値を反映、失敗時は元の値に戻し画面上でエラーを示す (詳細は実装層)。

### FR-003 カード更新 API

- 入力 PATCH `/api/cards/[id]` / body `{ "title": string }`
- 条件 指定 Card が存在 かつ title が trim 後 1〜200 文字
- 出力 200 OK / `{ "card": { "id": string, "title": string, "description": string | null, "order": number, "listId": string, "createdAt": string } }`
- 振る舞い trim 後のタイトルで UPDATE し、更新後レコードを返す。本 spec で更新できるフィールドは title のみ (description / order / listId は本 spec では変更対象外、body に含まれていても無視する)。

## 異常系

| ID | 条件 | HTTPステータス | レスポンス |
|---|---|---|---|
| E-001 | 存在しない cardId で PATCH | 404 | `{ "error": { "code": "NOT_FOUND", "message": "指定されたカードが見つかりません" } }` |
| E-002 | title フィールド欠落 | 400 | `{ "error": { "code": "VALIDATION_ERROR", "message": "titleは1〜200文字で入力してください" } }` |
| E-003 | title が trim 後 0 文字 | 400 | 同上 |
| E-004 | title が 201 文字以上 | 400 | 同上 |
| E-005 | title が文字列でない | 400 | 同上 |
| E-006 | DB 接続失敗などサーバー内部エラー | 500 | `{ "error": { "code": "INTERNAL_ERROR", "message": "サーバーエラーが発生しました" } }` |

## 境界条件

- title 0 文字 (trim 後) → 400 (画面上は元の値に戻す)
- title 1 文字 → 200
- title 200 文字 → 200
- title 201 文字 → 400
- 存在しない cardId → 404
- 編集後に値が変わっていない場合 → API 呼び出しなしで閲覧モードへ戻る (実装最適化として許容)
- バリデーションエラーと 404 が同時発生し得るケース (存在しない cardId + 空 title) → 404 を優先

## バリデーション

| フィールド | 必須 | 制約 |
|---|---|---|
| cardId (URL パス) | はい | 存在する Card.id と一致すること |
| title | はい | 文字列、trim 後 1〜200 文字 |
