# minimum_handson

同じカンバンアプリを**進め方（アプローチ）別**に作るハンズオンをまとめたディレクトリです。

- [`simple_prompt/`](./simple_prompt/) … プロンプトで進める版
- [`simple_skill/`](./simple_skill/) … スキルで進める版

各サブディレクトリが 1 つのハンズオンで、**その直下が「常に最新の稼働アプリ」**、
中の `1_.../2_...` が各ステップのスナップショット（ソースのコピー）です。
詳細は各サブディレクトリの README を参照してください。

## 実行ログ

[logs/](./logs/) には、第2章をClaude Opus 4.8で実行した正式な2つの統合セッションログを置いています。ログは対話の進み方を確認する参考記録です。完了判定は、各ハンズオンで生成した成果物と検証コマンドの結果で行います。
