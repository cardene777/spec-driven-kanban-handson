# chapter_2（教材 第2章）

カンバンアプリの土台を作り、ボード・リスト・カードの基本操作までを段階的に実装する章です。

## このディレクトリの運用

- **`chapter_2/` 直下が「常に最新の稼働アプリ」です。** 作業と動作確認はここで行います。
  - `node_modules` と `prisma/dev.db` を置きっぱなしにするので、**データは保持され**、起動も速いです。
  - 起動: このディレクトリで `npm run dev`（初回だけ `npm run setup` で依存インストール〜DB作成）。
- **各ステップの成果は、その時点のソースを `1_...` / `2_...` にコピーしたスナップショット**です。
  読み手はステップのディレクトリを開けば、そこまでの完成コードを確認できます。
- 新しいステップが終わったら、直下の最新アプリを次の番号のディレクトリにコピーして残します
  （下記「スナップショットの作り方」）。

## 起動

```bash
# 初回のみ（依存インストール + DB 作成）
npm run setup

# 2回目以降
npm run dev
```

http://localhost:3000 を開くと最新アプリが表示されます。DB は `chapter_2/prisma/dev.db` に保持されます。

## ステップ（スナップショット）一覧

| ステップ | ディレクトリ | 内容 | 状態 |
| --- | --- | --- | --- |
| 1 | [`1_board_list/`](./1_board_list/) | プロジェクト初期化 + Prisma/SQLite + ボード一覧・新規作成 | ✅ |
| 2 | [`2_board_detail/`](./2_board_detail/) | ボード詳細ページ + リスト追加・表示（404対応） | ✅ |
| 3 | [`3_card_create/`](./3_card_create/) | リスト内にカードを追加・表示 | ✅ |
| 4 | [`4_card_edit/`](./4_card_edit/) | カードタイトルのインライン編集（PATCH /api/cards/[id]） | ✅ |

> chapter_2 は継続中です。次のステップは `5_...` として保存していきます。

## スナップショットの作り方（ステップ完了時）

直下の最新アプリを、生成物を除いて次の番号のディレクトリへコピーします（DB は含めません）。

```bash
rsync -a \
  --exclude node_modules --exclude .next --exclude .env \
  --exclude 'prisma/dev.db' --exclude next-env.d.ts \
  --exclude '[0-9]*_*/' \
  ./ 5_xxx/
```
