# メインハンズオンで最初に使う4つのスキル

メインハンズオンの第02セクションで使う、本章用スキル4つの定義です。
新規プロジェクトに最初から導入し、仕様・設計・実装の流れを固定するために使います。

## スキル一覧

| スキル | 役割 |
|---|---|
| `/constitution` | 技術スタック・規約・非機能要件・権限ポリシー・用語集を定義 |
| `/spec` | 機能要件・異常系・境界条件・非機能要件・権限境界・用語参照を仕様に整理 |
| `/design` | データモデル・API・状態遷移・非機能の実装方針・権限チェック配置・監査ログを設計に反映 |
| `/implement` | 仕様と設計を読み、認証・権限チェック・構造化ロガー・監査ログを含むコードを生成 |

## 自分のClaude Codeに導入する方法

メインハンズオン用の新規プロジェクトを作り、その中の `.claude/skills/` にコピーします。

```bash
# プロジェクトルートで実行
cp -r chapters/05_full_handson/skills/{constitution,spec,design,implement} .claude/skills/
```

他の章の作業ディレクトリとは分けて作るため、既存のスキルやコードを上書きする必要はありません。

## 追加スキル6つとの関係

本章の追加スキル6つ（`/spec-review` `/ui-design` `/tdd` `/test` `/review` `/document`）も、同じ `.claude/skills/` に追加していきます。
追加スキルは本章用4つの出力を入力として受け取るため、先にこの4つを導入してから追加スキルを1つずつ載せていく順序になります。
