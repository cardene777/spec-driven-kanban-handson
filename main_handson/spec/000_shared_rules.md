# 共通ルール

Simple Kanban の全機能仕様が参照する共通規約。各機能 spec はここを参照し、再定義しない。

## 共通エラー形式

- すべてのエラー応答は次の形に統一する。
  ```json
  { "error": { "code": "<コード>", "message": "<日本語メッセージ>" } }
  ```
- HTTP ステータスとコードの対応。

  | 状況 | ステータス | code |
  |---|---|---|
  | バリデーション失敗 | 422 | VALIDATION_ERROR |
  | 未認証 | 401 | UNAUTHORIZED |
  | 権限不足 | 403 | FORBIDDEN |
  | 存在しないリソース | 404 | NOT_FOUND |
  | 重複・状態衝突 | 409 | CONFLICT |
  | 期限切れ（招待など、対象が失効済み） | 410 | GONE |
  | 予期しないサーバー側エラー | 500 | INTERNAL_ERROR |

- `409 CONFLICT` は「一意制約の重複」および「現在の状態では実行できない操作」に使う（例: email 重複、招待の重複、最後の owner の降格）。
- `410 GONE` は「対象は存在するが有効期限切れ・失効済み」に使う（例: 有効期限を過ぎた招待）。

## 権限ロール

- ロールは `owner` / `member` / `viewer`（constitution.md § 権限ポリシー参照）。
- 操作と必要権限。

  | 操作 | 必要権限 |
  |---|---|
  | ボードの作成・編集・削除、メンバー招待、権限変更 | owner |
  | リスト・カードの作成・編集・移動 | member 以上 |
  | 閲覧 | viewer 以上 |

- 権限の入口チェック順序は「**認証 → 対象存在 → 権限 → 入力検証**」で固定する。
  - 未認証は 401。
  - 閲覧権限のないリソースは、存在有無を漏らさないため 404 を返す（403 ではなく 404）。
  - 認証済みかつ閲覧権限はあるが操作権限が不足する場合は 403。

## order 規則

- 並び順を持つエンティティ（Board / List / Card）は整数 `order` を持つ。
- `order` は同一スコープ内で昇順に並べる。
  - Board: 全体で 1 スコープ（採番は全体）。ただし一覧は認証ユーザーがメンバーであるボードに絞り込むため、ユーザーから見た `order` の**連番の連続性は保証しない**（昇順であることのみを保証する。`spec/013_permissions.md` / `spec/001_boards.md`）。
  - List: 同一 `boardId` 内。
  - Card: 同一 `listId` 内。
- 新規作成時は、同一スコープ内の既存最大 `order` + 1 を採番する（0 件なら 0）。
- 並び替え操作は対象の `order` を更新する。

## 削除の連鎖（cascade）

- ボード削除時、配下の List / Card に加えて、そのボードの **BoardMembership**（`spec/013_permissions.md`）と **Invite**（`spec/012_member_invite.md`）も削除する。孤立した招待が承認されることを防ぐ。
- リスト削除時、配下の Card を状態問わず物理削除する（`spec/002_lists.md`）。

## ID 規則

- すべてのエンティティ ID はサーバー側で採番する文字列 ID とする（衝突しない一意な値）。
- クライアントから ID を指定しての作成は受け付けない。

## ログ方針（constitution.md § 非機能要件 参照）

- リクエストごとにリクエスト ID を発行する。
- 操作ログとエラーログの両方にリクエスト ID を付与し、あとから追跡できる形で残す。

## 日付方針

- `createdAt` / `updatedAt` はサーバー側で設定する。
- 作成時に両方を設定し、更新時に `updatedAt` を更新する。
- API 応答の日時は ISO 8601 文字列で返す。

## 一覧レスポンス構造

- 一覧 API のレスポンスは `{ "items": [ ... ] }` 形状で返す。
- items は該当スコープの `order` 昇順で並べる。
- データが 0 件でも `{ "items": [] }` を返す（画面側は空状態を表示する）。
