# ヘルプ: アカウント・メンバー招待・権限

対象読者: Simple Kanban をお使いの方、サポート担当の方

このページでは、アカウントの作成とログイン、ボードへのメンバー招待、メンバーの権限（ロール）の変更方法を説明します。

---

## 主要操作

| やりたいこと | 画面 |
|---|---|
| アカウントを作る | 「アカウント作成」画面 |
| ログインする | 「ログイン」画面 |
| ログアウトする | 画面左下のユーザーメニュー |
| メンバーを招待する | ボードの「メンバー」画面 |
| 招待リンクから参加する | 招待リンクを開いた画面 |
| メンバーの権限を変える | ボードの「メンバー」画面 |
| メンバーをボードから外す | ボードの「メンバー」画面 |

### ロール（権限）の種類

ボードごとに、メンバーは次の 3 つのいずれかの権限を持ちます。画面では `owner` / `member` / `viewer` と表示されます。

| 表示 | 呼び方 | できること |
|---|---|---|
| `owner` | オーナー | ボードの名前変更・削除、メンバーの招待・権限変更・削除、および member ができるすべて |
| `member` | メンバー | リストとカードの作成・編集・移動・アーカイブ・削除・復元、ラベルや期限の設定、および viewer ができるすべて |
| `viewer` | 閲覧者 | 閲覧・検索・絞り込みのみ |

ボードを作った方は、そのボードの `owner` になります。

## 操作手順

### 1. アカウントを作る

1. 「アカウント作成」画面を開きます（ログイン画面の「新規登録」からも移動できます）。
2. **名前**、**メールアドレス**、**パスワード**を入力します。
   - パスワードは **8〜200 文字**で、**英字、数字、記号をそれぞれ 1 文字以上**含めてください。
   - 名前は 1〜50 文字です。
3. 「アカウントを作成」を押します。
4. 作成に成功すると、そのままログインした状態でボード一覧が表示されます。

### 2. ログインする

1. 「ログイン」画面を開きます。
2. **メールアドレス**と**パスワード**を入力し、「ログイン」を押します。
3. 成功するとボード一覧が表示されます。

ログインしていない状態でボードの画面を開こうとすると、自動的にログイン画面へ移動します。

### 3. ログアウトする

1. 画面左のサイドバー下部にある、ご自身の名前とメールアドレスの部分を押します。
2. メニューから「ログアウト」を選びます。
3. ログイン画面に戻ります。

> ログアウトすると、**今お使いの端末（ブラウザ）のログイン状態だけ**が解除されます。他の端末でログインしたままの状態はそのまま残ります。

### 4. メンバーを招待する（オーナーのみ）

1. 招待したいボードを開き、右上の「メンバー」を押します。
2. 「メンバーを招待」の欄に、招待する方の**メールアドレス**を入力します。
3. **ロール**（`member` または `viewer`）を選びます。
   - オーナー権限は招待では付与できません。参加後に「メンバー一覧」で `owner` に変更してください。
4. 「招待する」を押します。
5. 画面に**招待リンク**が表示されます。このリンクをコピーして、招待する方に共有してください。

> 招待リンクの有効期限は **7 日間**です。
> 現在のバージョンでは招待メールは自動送信されません。表示されたリンクをご自身で共有してください。

### 5. 招待リンクからボードに参加する

1. 共有された招待リンクを開きます。
2. ログインしていない場合は、案内に従って**招待されたメールアドレスのアカウント**でログイン（またはアカウント作成）してください。
   - ログイン後、**もう一度招待リンクを開いてください**（⚠️ 注意事項の警告 1 を参照）。
3. ボード名と付与される権限が表示されるので、「参加する」を押します。
4. 参加すると、そのボードが開きます。

> **招待されたメールアドレスと同じアカウントでログインしている必要があります。** 別のアカウントでは参加できません（安全のための制限です）。

### 6. 招待を再送する・取り消す（オーナーのみ）

「メンバー」画面の「招待一覧」で、状態が **招待中** の招待に対して操作できます。

- **再送**: 新しい招待リンクを発行し、有効期限を再び 7 日間にします。**以前のリンクは使えなくなります。**
- **失効**: その招待を取り消します。以後、そのリンクでは参加できません。

状態が「参加済み」「失効」の招待には、再送・失効を実行できません。

### 7. メンバーの権限を変える（オーナーのみ）

1. ボードの「メンバー」画面を開きます。
2. 「メンバー一覧」で、対象の方の右側にあるロールの選択欄から `owner` / `member` / `viewer` を選びます。
3. 選んだ時点で変更が反映されます。

> **ボードにオーナーが 1 人しかいない場合、そのオーナーの権限は変更できません。**（操作は無効化されています。）
> 先に別の方を `owner` に変更してから、ご自身の権限を下げてください。

### 8. メンバーをボードから外す（オーナーのみ）

1. ボードの「メンバー」画面を開きます。
2. 対象の方の右側の「削除」を押し、確認メッセージで承認します。
3. 外された方は、以後そのボードを開けなくなります。

> **ボードにオーナーが 1 人しかいない場合、そのオーナーは削除できません。**
> なお、メンバーがご自身でボードを抜ける機能は、現在のバージョンにはありません。オーナーの方に依頼してください。

## エラーメッセージと対処法

### アカウント作成・ログイン

| 表示されるメッセージ | 原因 | 対処法 |
|---|---|---|
| メールアドレスまたはパスワードが正しくありません | ログイン情報が一致しない | メールアドレスとパスワードを確認してください。安全のため、どちらが誤っているかは表示されません。アカウントをお持ちでない場合は「新規登録」から作成してください |
| このメールアドレスは既に登録されています | 同じメールアドレスのアカウントが既にある | そのメールアドレスでログインしてください |
| メールアドレスの形式が正しくありません | `@` やドメイン（`example.com` など）が不足 | `名前@example.com` の形式で入力してください |
| パスワードは8〜200文字で、英字、数字、記号をそれぞれ1文字以上含めてください | 文字数または文字種の条件を満たしていない | 8〜200文字にし、英字、数字、記号をすべて入れてください |
| 名前は1〜50文字で入力してください | 名前が未入力、または長すぎる | 1〜50 文字で入力してください（空白のみは入力なしと同じ扱いです） |
| アカウントを作成できませんでした | 上記以外の理由で作成できなかった | 入力内容を確認し、しばらく待って再度お試しください |

### メンバーを招待するとき

| 表示されるメッセージ | 原因 | 対処法 |
|---|---|---|
| このメールアドレスへの招待は既に送信されています | 同じ相手への「招待中」の招待が残っている | 「招待一覧」から既存の招待リンクを再送するか、失効させてから作り直してください |
| このユーザーは既にボードのメンバーです | その方は既に参加済み | 「メンバー一覧」で権限を確認してください |
| メールアドレスの形式が正しくありません | 入力形式の誤り | `名前@example.com` の形式で入力してください |
| roleは member / viewer のいずれかです | 選べない権限が指定された | 招待では `member` か `viewer` を選んでください。オーナーにする場合は、参加後に権限を変更します |
| この操作を実行する権限がありません | オーナー以外が招待しようとした | ボードのオーナーに依頼してください |
| 招待を作成できませんでした | 上記以外の理由 | 入力内容を確認し、再度お試しください |

### 招待リンクを開いたとき

| 画面の表示 | 原因 | 対処法 |
|---|---|---|
| 招待が見つかりません | リンクが正しくない、または再送により古いリンクが無効になっている | ボードのオーナーに最新の招待リンクの再送を依頼してください |
| 招待の有効期限が切れています | 7 日を過ぎた、または招待が取り消された | ボードのオーナーに再送を依頼してください |
| この招待は使用済みです | すでに参加済みの招待 | ボード一覧から該当のボードを開いてください |
| 別のアカウントでログインしています | 招待されたメールアドレスと別のアカウントでログイン中 | 画面に表示されている宛先メールアドレスのアカウントでログインし直してください |
| 既にメンバーです | すでにそのボードに参加している | 「ボードを開く」から利用できます |
| 参加できませんでした | 上記以外の理由 | しばらく待って再度お試しください。解決しない場合はオーナーに再送を依頼してください |

### 招待の再送・失効、権限の変更・メンバー削除

| 表示されるメッセージ | 原因 | 対処法 |
|---|---|---|
| 最後のオーナーは降格できません。先に別のメンバーをオーナーにしてください | ボードにオーナーが 1 人しかいない | 先に別の方を `owner` に変更してから操作してください |
| 最後のオーナーは削除できません。先に別のメンバーをオーナーにしてください | 同上 | 同上 |
| この招待は再送できません（承認済みまたは失効済み） | 「招待中」以外の招待を操作した | 新しく招待を作成してください |
| この招待は失効できません（承認済みまたは失効済み） | 同上 | 操作は不要です |
| 指定されたメンバーが見つかりません | 対象の方が既にボードから外れている | 画面を再読み込みして最新の状態を確認してください |
| この操作を実行する権限がありません | オーナー以外が権限変更・削除・招待操作をしようとした | ボードのオーナーに依頼してください |
| ログインが必要です | ログイン状態が切れている | ログインし直してください |
| ロールを変更できませんでした / メンバーを削除できませんでした / 操作できませんでした | 上記以外の理由 | 画面を再読み込みし、再度お試しください |

## よくある質問

**Q. パスワードを忘れました。**
A. 現在のバージョンには、パスワードの再設定機能がありません。別のメールアドレスで新しくアカウントを作成し、ボードのオーナーに招待し直してもらってください。

**Q. ログインできません。何を確認すればよいですか。**
A. 次の順に確認してください。
1. メールアドレスの入力に誤り（全角文字、余分な空白など）がないか
2. パスワードの大文字・小文字が合っているか
3. そもそもアカウントを作成済みか（未作成なら「新規登録」から作成）
安全のため、メールアドレスとパスワードのどちらが誤っているかは画面に表示されません。

**Q. ボード一覧に、他の人のボードが表示されないのはなぜですか。**
A. ボード一覧には、**ご自身がメンバーになっているボードだけ**が表示されます。参加していないボードは表示されず、URL を直接開いても見ることはできません。

**Q. 招待リンクを他の人に転送しても大丈夫ですか。**
A. 参加できるのは**招待したメールアドレスのアカウントだけ**です。別の方がリンクを開いても参加できません。ただし、意図しない相手にリンクが渡った場合は、「メンバー」画面から招待を**失効**させてください。

**Q. 招待リンクの有効期限は？ 切れたらどうなりますか。**
A. 発行から 7 日間です。期限が切れた場合は参加できないため、ボードのオーナーに「再送」を依頼してください。再送すると期限が再び 7 日間になります。

**Q. 再送したら、前のリンクはどうなりますか。**
A. 使えなくなります。再送後は必ず**新しいリンク**を共有してください。

**Q. オーナーを他の人に引き継ぎたい。**
A. 「メンバー」画面で相手の権限を `owner` に変更してください。その後、ご自身の権限を `member` や `viewer` に下げられます（オーナーが 2 人以上いる状態にしてから操作してください）。

**Q. 自分でボードを抜けたい。**
A. 現在のバージョンには自分で退出する機能がありません。ボードのオーナーに、メンバーからの削除を依頼してください。

**Q. 閲覧者（viewer）にすると何ができなくなりますか。**
A. カードやリストの作成・編集・移動・削除ができなくなります。閲覧、検索、絞り込みは引き続き利用できます。操作しようとすると「この操作を実行する権限がありません」と表示されます。

**Q. 複数の端末で同時にログインできますか。**
A. できます。ログアウトすると、**その端末のログイン状態だけ**が解除されます。

**Q. 招待メールは届きますか。**
A. 現在のバージョンでは自動送信されません。オーナーの方が画面に表示された招待リンクをコピーして共有してください。

## ⚠️ 注意事項（仕様と画面で挙動が異なる点）

以下は、仕様の記載と現在の画面の動きが一致していない点です。修正方針は未確定のため、**現在の画面の動き**を上に記載しています。

### 警告 1: ログイン後に招待の画面へ自動で戻りません

- 仕様（`spec/012_member_invite.md`）では、招待リンクを開いてログインした後、**そのまま参加の画面に戻る**と記載されています。
- 現在の画面では、ログインするとボード一覧が表示されます。招待を受けるには、**もう一度招待リンクを開き直す**必要があります。
- ボードへの参加そのものは問題なく行えます（手順 5 を参照）。
