# 検索・絞り込み ユーザーヘルプ

Simple Kanban のボード内でカードを検索・絞り込みする操作を説明します。 検索と絞り込みは同時に使えます (すべての条件を満たすカードが表示されます)。

## キーワードで検索する

1. ボード詳細画面の上部にある検索バーにキーワードを入力します。
2. カードのタイトル、説明文、コメント本文のいずれかにキーワードを含むカードが表示されます。
- 空白 (半角 / 全角) で区切って複数のキーワードを入力すると、すべてのキーワードを含むカード (AND 条件) に絞られます。
- 大文字小文字は区別されません (英数字の場合)。 日本語の大文字小文字 / 全半角の同一視は保証されません。
- キーワードは 100 文字までです。 101 文字以上は「too_long」 相当のエラーになります。

## 絞り込む

検索バー横のフィルタ導線から、以下の条件を組み合わせて絞り込めます。

- ラベル = 選んだラベルのいずれかが付いたカード。 「ラベルなし」 を選ぶとラベル未付与のカードのみ。
- 期限 = 「期限なし」 / 「期限切れ」 / 「今日が期限」 / 「7 日以内」 / 期間指定 (開始日・終了日) のいずれか 1 つ。
- 担当者 = 「自分が担当」 / 特定の担当者 / 「担当者なし」 のいずれか 1 つ。
- ラベル / 期限 / 担当者はそれぞれ独立して指定でき、指定したものはすべて AND で合成されます。

「7 日以内」 は本日を含む 7 日間 (本日から本日 + 6 日まで) です。 期間指定は開始日・終了日の両端を含みます。

## 検索・絞り込みの利用条件

- 検索・絞り込みは `viewer` 以上のすべてのメンバーが利用できます。
- 該当するカードが 0 件のときは「該当するカードがありません」 相当の表示になります。

## うまくいかないケース

- 期限の絞り込みで「期限切れ」 と「今日が期限」 のように 2 種類以上を同時に指定 → 「invalid_due_date_options」 相当のエラーになります (期限の絞り込みは 1 種類まで)。
- 担当者の絞り込みで 2 種類以上を同時に指定 → 「invalid_assignee_options」 相当のエラーになります (担当者の絞り込みも 1 種類まで)。
- ラベルの絞り込みで別のボードのラベルを指定 → 「invalid_labels」 相当のエラーになります。

## よくある質問

- アーカイブ済み / 削除済みのカードを検索できますか → 現在のバージョンではアーカイブ機能が未実装のため、状態 (`status`) を `archived` / `deleted` にしても結果は常に 0 件です。 表示されるのは通常 (active) のカードのみです。
- 検索結果を並び替えできますか → 現在は更新が新しい順に固定です。 並び替えの切り替えは未対応です。
- 全ボードをまたいで検索できますか → 現在は 1 ボード内の検索のみです。
