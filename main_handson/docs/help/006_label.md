# ラベル ユーザーヘルプ

Simple Kanban のラベル (色付きの分類タグ) の作成 / 編集 / 削除、 カードへの付与 / 解除を説明します。 ラベルはボードごとに管理し、 1 枚のカードに何枚でも付けられます。

## ラベルを作成する

1. ボードのラベル管理画面を開きます。
2. 新規作成の導線から、ラベル名と色を入力します。
   - ラベル名 = 1-50 文字。
   - 色 = 8 色 (赤 `red` / 橙 `orange` / 黄 `yellow` / 緑 `green` / 青 `blue` / 紫 `purple` / 桃 `pink` / 灰 `gray`) から選びます。
3. 作成すると、そのボードのラベル一覧に名前順で追加されます。

同じボード内で既に使われている名前と同じ名前では作成できません (「duplicate_name」 相当のエラーになります)。 大文字と小文字は別の名前として扱われます (`Bug` と `bug` は共存できます)。

## ラベルを編集する

- ラベル管理画面またはカード詳細モーダルの編集導線から、名前と色 (どちらか片方または両方) を変更できます。
- 編集すると、そのラベルが付いている全カードで表示が即座に更新されます。

## ラベルを削除する

- ラベル管理画面の削除導線から削除します (削除確認を伴います)。
- 削除すると、そのラベルが付いていた全カードからも自動的に外れます。 カード自体は削除されません。

## カードにラベルを付ける / 外す

1. カード詳細モーダルのラベル領域を開きます。
2. 付けたいラベルを選ぶと、そのカードにラベルが付きます。
3. もう一度選ぶ (または解除導線を押す) と、ラベルが外れます。
- 既に付いているラベルをもう一度付けても重複しません。 付いていないラベルを外そうとしても問題は起きません (どちらも成功扱いです)。
- 付与 / 解除は、そのカードが属するボードのラベルに対してのみ行えます。

## 権限について

- ラベルの作成 / 編集 / 削除 / 付与 / 解除は `member` 以上の権限が必要です。
- `viewer` (閲覧者) がこれらの操作を行おうとすると「操作権限がありません」 相当の表示になります。 ラベルの表示は `viewer` でも可能です。

## よくある質問

- 好きな色 (カラーコード指定) を使えますか → 現在のバージョンでは 8 色の中からのみ選べます。 カスタムカラーは未対応です。
- ラベルの並び順を手動で変えられますか → 現在は名前順に固定です。 手動並び替えは未対応です。
- ラベルでカードを絞り込めますか → 検索・絞り込み機能でラベルフィルタを使えます。 詳細は `docs/help/008_search_filter.md` を参照してください。
