# 認証 ユーザーヘルプ

Simple Kanban のアカウント登録 / ログイン / ログアウトの操作を説明します。

## サインアップ (新規登録)

1. ブラウザで `/signup` を開きます。
2. 以下の 3 項目を入力します。
   - メールアドレス (例 `you@example.com`)。 大文字小文字は区別されず、小文字化されて保存されます。
   - パスワード (8 文字以上、 英字 + 数字 + 記号を全て含む。 例 `MyPass123!`)。
   - 表示名 (1-100 文字)。
3. 「登録する」 ボタンを押します。
4. 登録が成功すると、そのままログイン状態になりボード一覧 (`/`) に遷移します。

登録できないケース。

- 既に登録済みのメールアドレス → 「このメールアドレスは既に登録されています。」 と表示されます。 大文字小文字違いも重複扱いです。
- パスワードが 7 文字以下 → 「too_short」 と表示されます。
- パスワードが英字だけ / 数字だけ / 記号なし → 「weak」 と表示されます。
- 表示名が空 or 101 文字以上 → フィールドエラーが表示されます。

## ログイン

1. ブラウザで `/login` を開きます。
2. 登録済みの メールアドレス / パスワード を入力します。
3. 「ログインする」 ボタンを押すと、指定された戻り先 (`returnTo` パラメータ) またはボード一覧 (`/`) に遷移します。

失敗時の表示。

- メールアドレスまたはパスワードが正しくない場合、常に 「メールアドレスまたはパスワードが正しくありません。」 と表示されます (「メール未登録」 / 「パスワード違い」 の区別はしません、 セキュリティ上の理由)。

## ログアウト

- ボード一覧画面 (`/`) 右上の 「ログアウト」 ボタンを押すと、現在のセッションが破棄され、ログイン画面 (`/login`) に戻ります。
- ログアウトは冪等です。 未ログイン状態で呼んでもエラーになりません。

## セッションの有効期限

- ログイン / サインアップから 7 日間、 セッションが自動維持されます。
- 7 日を過ぎると自動的にログアウト状態になり、認証が必要な画面 (`/` や `/boards/*`) は `/login` にリダイレクトされます。

## 招待経由の参加

- 他のユーザーから招待 URL (`/invites/<token>`) を受け取った場合の手順は `docs/help/012_member_invite.md` を参照してください。

## 開発環境の default ユーザー

- 開発時、`npm run db:seed` を実行すると、以下の既定ユーザーが作成されます。
  - メールアドレス = `default@example.com`
  - パスワード = `Default!123`
  - 表示名 = `Default User`
- このユーザーで `/login` からログインし、ボードを作成 / 招待をテストできます。

## トラブルシューティング

- 認証必須画面 (`/`) を開いても `/login` にリダイレクトされる = Cookie が無い / 期限切れ / 別ドメイン。 Cookie の `sid` が発行されているかを DevTools の Application → Cookies で確認してください。
- サインアップの入力欄でパスワードが受理されない = `MyPass123!` のように英字 + 数字 + 記号を含めているか確認してください。
