# 担当者 ユーザーヘルプ

Simple Kanban のカードに担当者を割り当てる操作を説明します。 1 枚のカードには最大 10 名まで担当者を設定できます。

## 担当者を追加する

1. カードを開いてカード詳細モーダルを表示します。
2. 担当者領域の「担当者を追加する」 導線を押します。
3. 候補の中から追加したいメンバーを選びます。
4. 追加すると、担当者一覧の末尾にそのメンバーが表示されます。

追加できるのは、そのカードが属するボードのメンバー (`viewer` 以上) です。 追加操作は `member` 以上の権限が必要です。

## 担当者を外す

- 各担当者バッジの横にある解除導線を押すと、そのメンバーが担当者から外れます。
- 解除操作は `member` 以上の権限が必要です。
- いったん外したメンバーを再度追加することもできます (追加した順で末尾に並びます)。

## 担当者を確認する

- カード詳細モーダルの担当者領域に、割り当てられた順 (追加が早い順) で担当者が表示されます。
- 担当者が 0 人のカードは「未割当」 相当の表示になります。
- `viewer` (閲覧者) は担当者の一覧を見ることはできますが、追加 / 解除の導線は表示されません。

## 追加できないケース

- 既にそのカードの担当者になっているメンバーを再度追加 → 「このユーザーは既に担当者に設定されています」 相当のメッセージが表示されます。
- 担当者が既に 10 名いるカードにさらに追加 → 「担当者は最大 10 名までです」 相当のメッセージが表示されます。
- そのボードのメンバーではないユーザーを追加 → 「このユーザーはボードメンバーではありません」 相当のメッセージが表示されます。
- `viewer` (閲覧者) が追加 / 解除を行おうとした → 「操作権限がありません」 相当の表示になります。

## よくある質問

- 自分自身を担当者にできますか → できます。 自分をアサインする場合も通常の追加操作と同じで、`member` 以上の権限が必要です。
- 担当者にアサインされたら通知は届きますか → 現在のバージョンでは通知機能はありません (メール / アプリ内通知とも未対応)。
- 担当者でカードを絞り込めますか → 検索・絞り込み機能で担当者フィルタを使えます。 詳細は `docs/help/008_search_filter.md` を参照してください。
