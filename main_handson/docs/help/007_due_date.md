# 期限 ユーザーヘルプ

Simple Kanban のカードに期限 (日付) を設定 / 変更 / 解除する操作を説明します。 期限は日付単位で管理し、 時刻は扱いません。

## 期限を設定する

1. カードを開いてカード詳細モーダルを表示します。
2. 期限領域の「期限を設定する」 導線から、日付を選びます。 日付は `YYYY-MM-DD` 形式 (例 `2026-07-20`) です。
3. 設定すると、モーダルとカード行に期限の日付が表示されます。
- 過去の日付も設定できます (期限切れとして表示されます)。
- 設定 / 変更 / 解除は `member` 以上の権限が必要です。

## 期限を変更する / 解除する

- 既に期限が設定されているカードは、変更導線から別の日付を選ぶと上書きされます。
- 「期限を解除する」 導線を押すと期限がなくなり、日付表示が消えます。

## 期限の見え方

期限は本日 (サーバーの日付) との比較で 4 通りに表示されます。

| 状態 | 条件 | カード行 / モーダルの表現 |
|---|---|---|
| 期限なし | 未設定 | 期限バッジ非表示 |
| 期限内 | 本日より後 | 通常表現 |
| 今日が期限 | 本日と同一 | 注意表現 |
| 期限切れ | 本日より前 | 警告表現 |

## 入力できないケース

- `YYYY-MM-DD` 以外の形式 (`2026/07/20` / 時刻付き / 空文字 等) → 「invalid_format」 相当のエラーになります。
- 存在しない日付 (`2026-02-30` 等) → 「invalid_date」 相当のエラーになります。
- `viewer` (閲覧者) が期限を変更しようとした → 「操作権限がありません」 相当の表示になります。

## よくある質問

- 期限に時刻 (何時まで) を設定できますか → 現在のバージョンでは日付のみです。 時刻は扱いません。
- 期限が近づくと通知は届きますか → 現在のバージョンでは通知機能はありません。
- 期限でカードを絞り込めますか → 検索・絞り込み機能で「期限切れ」 「今日が期限」 「7 日以内」 「期間指定」 などのフィルタを使えます。 詳細は `docs/help/008_search_filter.md` を参照してください。
- カードをアーカイブすると期限はどうなりますか → 現在のバージョンではアーカイブ機能自体が未実装のため、 アーカイブに伴う期限の挙動はありません。
