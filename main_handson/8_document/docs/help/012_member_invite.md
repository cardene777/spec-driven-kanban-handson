# メンバー招待 ユーザーヘルプ

Simple Kanban のメンバー招待、承認、再送、失効の操作を説明します。

## 招待を作成する (owner)

1. ボード詳細画面 (`/boards/<boardId>`) を開きます。
2. 「メンバー / 招待の管理へ →」 リンクから `/boards/<boardId>/members` に遷移します。
3. 「新規招待を作成」 セクションで以下を入力します。
   - メールアドレス (招待先のメール)。 大文字小文字は自動で小文字化されます。
   - ロール (`member` または `viewer` から選択。 `owner` は招待経由で追加できません)。
4. 「招待作成」 ボタンを押すと、招待 URL が青色のバナーで 1 度だけ表示されます。
   - この URL は再取得できません。 コピーして相手に共有してください (メール、Slack、印刷など)。
5. 有効期限は発行時から 7 日間です。

## 招待 URL を受け取ったら (被招待者)

1. 招待 URL (`/invites/<token>`) をブラウザで開きます。
2. 招待の内容 (ボード名、付与されるロール、有効期限) が表示されます。
3. 未ログインの場合は 「ログインして承認する」 リンクからログイン画面へ遷移し、ログイン後に招待画面に戻ります。
   - アカウントを持っていない場合は、`/signup` から新規登録してください。
4. ログイン中の場合は 「承認する」 ボタンで承認します。
5. 承認に成功するとボード詳細画面 (`/boards/<boardId>`) に遷移します。

## 承認できないケース

| ケース | 表示 | 対応 |
|---|---|---|
| 招待が期限切れ | 「この招待は期限切れです。」 | ボード owner に再送を依頼してください。 |
| 招待が失効済み (owner が revoke 済み) | 「この招待は失効済みです。」 | ボード owner に新規招待を依頼してください。 |
| 招待が既に使用済み (別の URL で承認された) | 「この招待は既に使用されています。」 | ボード owner に新規招待を依頼してください。 |
| 既にそのボードのメンバー | 「既にこのボードのメンバーです。」 | 招待は消費されません。 該当ボードにそのままアクセスできます。 |

## 招待の再送 (owner)

1. `/boards/<boardId>/members` の 「Pending の招待」 一覧で対象行の 「再送」 ボタンを押します。
2. 新しい招待 URL が青色のバナーで表示されます。 旧 URL は無効になります。
3. 有効期限は再送時点から 7 日に更新されます。

## 招待の失効 (owner)

1. `/boards/<boardId>/members` の 「Pending の招待」 一覧で対象行の 「失効」 ボタンを押します。
2. 確認ダイアログで OK すると招待が `revoked` 状態になり、以降その URL は承認できなくなります。
3. `accepted` / `revoked` 済みの招待は再度失効できません (「再送に失敗しました」 相当のメッセージが出ます)。

## 招待の管理範囲

- 招待の作成 / 再送 / 失効 / 一覧閲覧はすべて `owner` のみ実行可能です。
- `member` / `viewer` は招待管理画面にアクセスできず、メンバー一覧の閲覧のみ可能です。

## セキュリティ上の注意

- 招待 URL は「知っている人が承認できる」 秘密トークンを含みます。 SNS 等で不特定多数に公開しないでください。
- 招待 URL の平文は招待作成 / 再送の直後にのみ表示され、以降 API からは取得できません。 再入手には失効 → 再作成 (または再送) が必要です。
- 招待メールアドレスと承認ユーザーのメールアドレスは一致しなくても承認可能です (`spec/012_member_invite.md § FR-03`)。 URL を持っている = 承認権利、 の設計です。

## トラブルシューティング

- 「既にこのボードのメンバーです。」 と表示された = 既に別経路で追加済みです。 該当ボードは自分のボード一覧 (`/`) から開けます。
- 招待 URL を紛失した = owner に再送を依頼してください。 再送すると新 URL が発行され、旧 URL は無効化されます。
