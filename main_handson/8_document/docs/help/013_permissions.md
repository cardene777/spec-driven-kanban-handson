# 権限管理 ユーザーヘルプ

Simple Kanban のボード内メンバーの権限 (ロール) 管理を説明します。

## ロールの種類

| ロール | できること |
|---|---|
| `owner` | ボードの編集 / 削除、 メンバー招待 / ロール変更 / 削除、 リスト・カード・コメントの CRUD、 閲覧 |
| `member` | リスト・カード・コメントの CRUD、 閲覧、 自身の脱退 |
| `viewer` | 閲覧のみ、 自身の脱退 |

- 1 ボード = 1 ユーザーあたり 1 ロールです。
- 招待経由で追加した場合、 招待時に指定した `member` / `viewer` のロールで参加します (owner は招待経由では追加できません)。

## メンバー一覧を見る

1. ボード詳細画面から 「メンバー / 招待の管理へ →」 リンクを押します。
2. `/boards/<boardId>/members` にメンバー一覧が表示されます。 並び順は `owner` → `member` → `viewer`。 同ロール内は参加日時の昇順。
3. `viewer` / `member` は閲覧のみ可能で、ロール変更 / 削除ボタンは表示されません。 自分の 「脱退」 ボタンのみ表示されます。

## ロールを変更する (owner)

1. `/boards/<boardId>/members` を開きます。
2. 対象メンバーの行のドロップダウンで `owner` / `member` / `viewer` を選び直します。
3. 変更は即時反映され、対象ユーザーの次回 API 呼出から新ロールで判定されます。

制限。

- ボード内に owner が 1 名しかいない状態でその owner を `member` / `viewer` に降格しようとすると、 「最後の owner は降格 / 削除できません。」 と表示されて失敗します (`422 last_owner`)。
- 別ユーザーを先に owner に昇格してから、 元の owner を降格する経路のみ可能です。
- 同じロールへの変更 (owner → owner など) は成功扱い (副作用なし)。

## メンバーを削除する (owner)

1. 対象メンバーの行の 「削除」 ボタンを押します。
2. 確認ダイアログで OK すると削除されます。
3. 削除された メンバーは以降ボード配下の API を呼ぶと `404` (存在しないボード扱い) が返ります。

制限。

- 最後の owner の削除は禁止です (同上の 「最後の owner は削除できません」)。

## 自分でボードから脱退する

1. `/boards/<boardId>/members` を開き、自分の行の 「脱退」 ボタンを押します。
2. 確認ダイアログで OK すると自分の `BoardMembership` が削除され、ボード一覧 (`/`) に戻ります。
3. 自分が 「最後の owner」 の場合は脱退できません (別の owner を追加してから再度脱退してください)。

## 各ロールの API 権限まとめ

| 操作カテゴリ | owner | member | viewer |
|---|---|---|---|
| ボード編集 / 削除 | ✓ | ✕ | ✕ |
| リスト / カード / コメント 作成・編集・削除 / 並び替え | ✓ | ✓ | ✕ |
| 閲覧 (ボード、リスト、カード、コメント、メンバー一覧) | ✓ | ✓ | ✓ |
| メンバー招待 / 再送 / 失効 | ✓ | ✕ | ✕ |
| メンバーのロール変更 | ✓ | ✕ | ✕ |
| メンバーの強制削除 (他人) | ✓ | ✕ | ✕ |
| 自身の脱退 | ✓ (最後 owner を除く) | ✓ | ✓ |

## トラブルシューティング

- 「操作権限がありません」 と表示される = 現在のロールでは実行できない操作です。 owner に依頼してください。
- 「最後の owner は降格 / 削除できません」 = ボードには常に 1 名以上の owner が必要です。 別の owner を先に用意してから再度操作してください。
- 自分の脱退が失敗する = ロールが owner かつ 1 名の owner の場合です。 別ユーザーを owner に昇格してから再度実行してください。
