# Comment Spec Input

カードにコメントを投稿、一覧取得、削除する機能の仕様を書くための入力です。
レビューで突合しやすいように、機能要件、異常系、境界条件、権限境界を分けます。

## 読み込むファイル

- constitution.md
- spec/000_shared_rules.md
- spec/001_boards.md
- spec/002_lists.md
- spec/003_cards.md
- spec/005_card_detail.md

## 作成するファイル

- spec/010_comment.md

## 対象

- カードにコメントを投稿する
- カードのコメント一覧を取得する
- 自分のコメントを削除する
- ownerが他人のコメントを削除する

## 入力制約

- コメント本文は1〜2000文字
- 空文字は422
- 2001文字以上は422
- 存在しないカードは404

## 権限

- member以上は投稿できる
- viewerは一覧取得のみできる
- コメント削除は投稿者本人またはownerのみ

## 非機能

- コメント本文は保存時に長さ制限と正規化を行い、表示時にコンテキストに応じてエスケープする
- 一覧取得は投稿日時の降順
- 投稿、削除は操作ログに残す

## 出力ルール

- 指定した1ファイルだけを作成または更新する
- 機能要件、受入条件、異常系、境界条件、バリデーション、権限境界、非機能要件、未決事項を分けて書く
- レビューで突合できるように、各FRに対応するAPI、ステータスコード、権限を明記する
- 不明点がある場合は、仕様を書き始める前に質問する
- 作成または更新したファイル一覧を最後に示す
