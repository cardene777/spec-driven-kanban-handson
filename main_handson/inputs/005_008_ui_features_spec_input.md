# UI Feature Spec Input

カード詳細、ラベル、期限、検索、絞り込みの仕様を書くための入力です。
既存のボード、リスト、カード、カード移動関連仕様を前提にします。

## 読み込むファイル

- constitution.md
- spec/000_shared_rules.md
- spec/001_boards.md
- spec/002_lists.md
- spec/003_cards.md
- spec/004_card_movement_archive_restore.md

## 作成するファイル

- spec/005_card_detail.md
- spec/006_label.md
- spec/007_due_date.md
- spec/008_search_filter.md

## 対象

- カード詳細では、タイトル、説明文、ラベル、期限、担当者、コメントの表示領域を定義する
- ラベルでは、ボード単位のラベル作成、編集、削除、カードへの付与と解除を定義する
- 期限では、カードへの期限設定、変更、解除、期限切れ表示を定義する
- 検索と絞り込みでは、カードタイトル、説明文、コメント本文の検索と、ラベル、期限、担当者、アーカイブ状態による絞り込みを定義する

## 入力制約

- カード説明文は0〜2000文字
- ラベル名は1〜50文字
- ラベル色は事前定義された色のみ
- 期限は日付のみで時刻は扱わない
- 検索キーワードは0〜100文字

## 権限

- member以上はカード詳細の編集、ラベル操作、期限操作ができる
- viewerは閲覧と検索、絞り込みのみできる

## 異常系と境界条件

- 存在しないカード、ラベルは404
- 入力制約違反は422
- ラベル0件、期限未設定、検索結果0件を定義する

## 出力ルール

- 指定した4ファイルだけを作成または更新する
- 担当者の割当とコメント投稿は `spec/005_card_detail.md` に書き、コメント本文の検索と担当者による絞り込みは `spec/008_search_filter.md` に書く
- 指定した4ファイル以外を変更する必要がある場合は、変更理由とファイル名を示し、書き出す前に確認を受ける
- 各仕様には機能要件、受入条件、異常系、境界条件、バリデーション、権限境界、画面状態、未決事項を分けて書く
- 後続のui-designで使えるように、画面に出る要素と操作ごとの状態を明記する
- 既存仕様と矛盾する可能性がある場合は、矛盾する条件を挙げ、どちらを採用するか質問する
- 完了時に、作成または更新したファイルを一覧で報告する
