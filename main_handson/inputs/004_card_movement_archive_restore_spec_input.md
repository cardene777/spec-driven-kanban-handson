# Card Movement Archive Restore Spec Input

カード移動、ドラッグ&ドロップ、アーカイブ、削除と復元の仕様を書くための入力です。
既存のボード、リスト、カード仕様を前提にします。

## 読み込むファイル

- constitution.md
- spec/000_shared_rules.md
- spec/001_boards.md
- spec/002_lists.md
- spec/003_cards.md

## 作成するファイル

- spec/004_card_movement_archive_restore.md

## 対象

- カードを同じリスト内で並べ替える
- カードを別リストへ移動する
- リスト自体を並べ替える
- カードをアーカイブする
- アーカイブ済みカードを復元する
- カードを削除する
- 削除済みカードを復元する

## 入力と制約

- cardId、sourceListId、targetListId、targetOrderを受け取る
- listId、targetOrderを受け取る
- targetOrderは0以上の整数
- 存在しないIDは404
- 権限不足は403
- 不正な並び順は422

## 権限

- member以上はカード移動、アーカイブ、復元ができる
- ownerのみ完全削除ができる
- viewerは閲覧のみ

## 境界条件

- 空リストへの移動
- リスト先頭への移動
- リスト末尾への移動
- 同じ位置への移動
- すでにアーカイブ済みのカードへの再アーカイブ
- すでに復元済みのカードへの再復元

## 非機能

- 並び順更新はconstitution.mdの性能目標に従う
- アーカイブ、削除、復元は操作ログに残す
- 同時更新時の扱いを明記する

## 出力ルール

- 指定した1ファイルだけを作成または更新する
- 指定した1ファイル以外が必要な場合は、作業前に理由と対象ファイルを示して確認する
- 機能要件、異常系、境界条件、バリデーション、権限境界、非機能要件、未決事項を分けて書く
- 既存仕様と矛盾しそうな場合は、矛盾箇所と判断点を示してから質問する
- 不明点がある場合は、仕様を書き始める前に質問する
- 作成または更新したファイル一覧を最後に示す
