# Simple Kanban Constitution

## プロジェクト概要

- **名前**: Simple Kanban
- **概要**: 小規模チームがタスクを「ボード・リスト・カード」で管理する Web アプリ。
- **対象ユーザー**: 小規模チーム。
- **範囲**: 仕様・設計・実装・テスト・レビュー・ドキュメントを分けて管理する。

## 技術スタック

| 分類 | 採用技術 |
|---|---|
| フレームワーク | Next.js 16（App Router、`create-next-app` は `--webpack` で初期化） |
| 言語 | TypeScript |
| データベース | SQLite（ローカル開発用） |
| ORM | Prisma 7（`@prisma/adapter-better-sqlite3` の adapter 方式、`prisma-client` generator、output は `../generated/prisma`） |
| スタイル | Tailwind CSS |
| テスト | Vitest 4 |
| パッケージマネージャ | npm |
| Lint | ESLint を直接使う（`next lint` は使わない） |
| ランタイム | Node.js 20.19 以上 |

## コーディング規約

- API は Next.js の Route Handler で実装する。
- データアクセスは Prisma に集約する。
- HTTP ステータスは次のとおり返す。
  - バリデーション失敗: `422`
  - 未認証: `401`
  - 権限不足: `403`
  - 存在しないリソース: `404`
  - 予期しないサーバー側エラー: `500`
- エラー応答は次の形に統一する。
  ```json
  { "error": { "code": "<コード>", "message": "<日本語メッセージ>" } }
  ```
  - コードは `VALIDATION_ERROR` / `UNAUTHORIZED` / `FORBIDDEN` / `NOT_FOUND` / `INTERNAL_ERROR` を用いる。
- テストは仕様の正常系・異常系・境界条件を確認できる単位で置く。
- 認証・権限・ログなど複数機能で共有する処理は `lib/` に集約する。

## 基本原則

- 仕様・設計・実装・テスト・レビュー・ドキュメントを分けて管理する。
- 仕様と設計に書かれていない機能は追加しない。
- 共有処理（認証・権限・ログ等）は `lib/` に集約し、重複実装しない。

## 非機能要件

### 性能

- 一覧 API の P95 レスポンスタイムは 200ms 以内を目標とする（ローカル SQLite・少量データ前提の開発時安全域）。
- 書き込み API の P95 レスポンスタイムは 300ms 以内を目標とする（同上）。

### 可用性

- 稼働率（SLA）の数値目標は設けない（ローカル開発環境が対象のため）。

### セキュリティ

- ローカル開発用の SQLite を使い、機密データは扱わない。

### 運用

- 操作ログとエラーログは、あとから追跡できる形で残す。
- リクエスト ID を発行し、操作ログとエラーログの両方に付与する。

## 権限ポリシー

### ロール

| ロール | 説明 | デフォルト権限 |
|---|---|---|
| owner | ボードの所有者 | ボードの作成・編集・削除、メンバー招待、権限変更 |
| member | ボードのメンバー | リスト・カードの作成・編集・移動、コメント投稿 |
| viewer | 閲覧者 | 閲覧のみ |

### 操作と必要権限

| 操作 | 必要権限 |
|---|---|
| ボードの作成 | owner |
| ボードの編集 | owner |
| ボードの削除 | owner |
| メンバー招待 | owner |
| 権限変更 | owner |
| リストの作成・編集・移動 | member 以上 |
| カードの作成・編集・移動 | member 以上 |
| コメント投稿 | member 以上 |
| 閲覧 | viewer 以上 |

### 権限チェックの実装方針

- 未ログインは `401`、権限不足は `403` を返す。
- 閲覧権限のないリソースは、存在有無を漏らさないため `404` を返す。
- 入口チェックは「**認証 → 対象存在 → 権限 → 入力検証**」の順で判定する。

## 用語集

| 用語 | 英訳 | 定義 |
|---|---|---|
| ボード | Board | カンバンアプリの最上位単位。 |
| リスト | List | ボード内の列。 |
| カード | Card | タスクを表す項目。 |
| 担当者 | Assignee | カードに割り当てられたユーザー。 |
| 期限 | Due Date | カードの完了予定日。 |
| コメント | Comment | カードに残す会話。 |
| アーカイブ | Archive | 表示対象から外す操作。 |
| 復元 | Restore | アーカイブや削除状態から戻す操作。 |
| ラベル | Label | カードに付与する分類タグ。 |
